# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately, not in a public issue:

1. Open the repository's **Security** tab on GitHub.
2. Select **Report a vulnerability**.
3. Describe the problem, the FlashModel version, your Claude Code version, and
   the steps to reproduce it.

Only the maintainer sees the report. You will get an acknowledgement within 7
days, and updates as the report is investigated. Once a fix is released, the
advisory is published, with credit to you if you want it.

## Supported versions

Only the latest release on the `main` branch receives security fixes.

## Scope

FlashModel is a Claude Code mod: it runs inside Claude Code, on your computer,
with your permissions. Its behavior is documented in the README's
"Transparency and security" section and in [PRIVACY.md](PRIVACY.md). Reports
about Claude Code itself go to Anthropic, not to this repository.
